                       📊 Sales Analytics Dashboard

An end-to-end business intelligence project using Python, Tableau Public, and the Superstore dataset to analyze sales performance, profitability, customer behavior, and product trends.

🔍 Project Overview

This project focuses on transforming raw sales data into actionable business insights. The analysis explores regional performance, category profitability, customer behavior, and product-level trends.

Objectives

Analyze overall sales and profit performance
Identify top-performing regions and categories
Discover loss-making products and sub-categories
Identify high-value customers
Create an interactive Tableau dashboard
Generate business recommendations
